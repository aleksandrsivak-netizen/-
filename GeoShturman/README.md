# ГеоШтурман · «Полёт вслепую»

Резервная навигация воздушного судна **без GNSS** — по данным радиовысотомера и
цифровой карты рельефа (DEM). Демонстрационный веб-стенд для хакатонного кейса.

> Проект строго **гражданский**: логистика в труднодоступные районы, безопасность
> полётов, резервная навигация, постфактум-анализ маршрута.

## 1. Описание кейса

Коммерческая авиакомпания доставляет грузы лёгкими беспилотными и
опционально-пилотируемыми судами в удалённые районы: таёжные посёлки,
геологоразведочные лагеря, арктические метеостанции, высокогорные базы.
Маршруты идут над безориентирными пространствами (тайга, тундра, степи, горные
плато), где GNSS/GPS/ГЛОНАСС часто нестабилен: высокие широты, плохая спутниковая
геометрия, ущелья, радиопомехи, джамминг/спуфинг, геомагнитные бури.

При потере GNSS судно продолжает навигацию по трём независимым источникам:

1. **радиовысотомер** — высота над землёй (AGL);
2. **барометрическая высота** — абсолютная высота полёта (MSL, по умолчанию 1500 м);
3. **цифровая карта рельефа DEM**.

---

## 2. Что делает приложение

- преобразует данные радиовысотомера (формат **NMEA-0183 v3**) в профиль абсолютных
  высот рельефа под трассой: `terrain_msl = baro_msl − radio_agl`;
- строит эталонные профили для всех азимутов (0…360°, шаг 1°) из стартовой точки;
- находит азимут и смещение с **максимальной корреляцией** с DEM;
- вычисляет вектор движения: путевую скорость, путевой угол (азимут), координаты;
- визуализирует результат: карту высот с траекторией, тепловую карту корреляции,
  сравнение профилей, метрики точности (RMSE, CEP/SEP, confidence).


**автономный demo-режим** — данные синтезируются в браузере (DEM, трек NMEA,
корреляция, метрики), чтобы стенд всегда был демонстрабелен жюри.

## 6. Локальный запуск без Docker (для разработки фронтенда)

Фронтенд можно открыть и без бэкенда — он перейдёт в demo-режим:

```bash
cd backend/app/static
python -m http.server 5173
# открыть http://localhost:5173
```

Полный стек (когда готовы части Агентов 1 и 2):

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# http://localhost:8000
```

```json
{

  "search_radius_m": 2000, "enable_kalman": true, "seed": 42
```

## 8. Как работает алгоритм простыми словами

1. Радиовысотомер на каждом такте измеряет высоту до земли (AGL).
2. Барометр знает абсолютную высоту полёта над уровнем моря (MSL).
3. Разность даёт абсолютную высоту рельефа под судном: `terrain = baro − radio`.
4. Получается «профиль рельефа» — как кардиограмма местности вдоль маршрута.
5. Этот профиль накладывается на цифровую карту высот DEM для всех направлений
   (азимут 0…360°) и смещений.
6. Там, где профиль совпал с картой лучше всего (максимум корреляции), и находится
   судно — отсюда координаты, путевой угол и скорость.

## 9. Гражданские сценарии применения

- **Доставка медикаментов** в удалённые таёжные посёлки.
- **Снабжение арктических метеостанций** при нестабильном GNSS.
- **Геологоразведка** — доставка оборудования и данных в полевые лагеря.
- **Высокогорные базы** — маршруты в долинах и над плато.
- **Постфактум-анализ полёта** — восстановление траектории при потере сигнала.
- **Безопасность полётов** — дополнительный навигационный слой для гражданских ВС.

---

## 10. Ограничения прототипа

- DEM и трек NMEA в demo-режиме **синтетические** (для воспроизводимой демонстрации).
- Корреляционный поиск в demo-режиме упрощён; «боевой» алгоритм — в `app/core` (Агент 1).
- Нет реальной картографической проекции и привязки к геоиду — координаты условны.
- Точность зависит от выраженности рельефа: над «плоской» местностью падает.

## 11. Что улучшить после хакатона

- Реальные DEM-тайлы (Copernicus GLO-30 / SRTM / ALOS) и корректная геопривязка.
- Фильтр Калмана/частичный фильтр для непрерывного трекинга в реальном времени.
- Адаптация к плоскому рельефу (детектор «низкой информативности» участка).
- Оптимизация под бортовой маломощный вычислитель (FFT-корреляция, даунсэмплинг).
- WebSocket-стрим телеметрии для живого режима, а не разовый расчёт.
